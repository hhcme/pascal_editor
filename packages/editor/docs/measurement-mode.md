# 3D 测量模式说明

本文档描述编辑器 3D 测量模式的当前能力、计算口径、近似值规则和性能策略。

## 代码入口

- 交互与面板：`packages/editor/src/components/editor/measurement-mode.tsx`
- 几何与指标计算：`packages/editor/src/lib/measurement.ts`
- 临时测量状态：`packages/editor/src/store/use-measurement-mode.ts`

## 模式概览

### 距离

- `自由距离`：保留真实 3D 距离。
- `水平距离`：锁定起点高度，只测平面距离。
- `垂直距离`：锁定起点平面位置，只测高差。
- `路径测距`：沿连续墙体或围栏中心线累计长度。

距离模式支持吸附到：

- 墙/围栏端点
- 墙/围栏中点
- 墙/围栏中心线
- 场地、区域、楼板、吊顶的轮廓顶点
- 轮廓边中点
- 面中心
- 通用对象面中心
- 楼层基准面

### 面积

- 墙体：单侧毛面积、洞口扣减面积、单侧净面积、双侧展开面积
- 楼板/吊顶：毛投影面积、洞口扣减面积、净投影面积
- 区域：套内面积
- 屋顶：投影面积、斜面展开面积
- 楼层/建筑：楼层净面积、总楼地面面积、占地投影面积、屋顶投影面积

### 体积

- 墙体：毛实体体积、洞口扣减体积、净实体体积
- 楼板/吊顶：毛实体、扣减、净实体
- 区域：房间净体积
- 楼层/建筑：包络体积
- 通用构件：实体或包络体积

### 净空

- 房间/楼层：净高、梁下净高、最高女儿墙高
- 门：门净宽、门净高、顶部净空
- 窗：窗台高、窗净高、顶部净空
- 家具/构件：离地高度、顶部净空、前后左右净距、最近水平净距
- 平屋顶/平屋顶分段：女儿墙高（当前口径使用 `roof-segment.wallHeight`）

### 角度

- 屋顶：坡度角、坡度百分比、坡向、平面旋转
- 楼梯：整体倾角、整体坡度、扫掠角、单步转角
- 墙体/围栏：线角度
- 双选线性对象：两墙夹角、两边夹角

### 周长

- 场地/建筑/楼层/区域/屋顶：周长、面宽、进深、前后左右退距
- 区域化对象支持分跨：面宽分跨、进深分跨
- 门窗：洞口开间、安装进深
- 墙体/围栏：长度、厚度

### 轴网

- 支持多选两条以上近似平行的墙体、围栏或草图线
- 两条线时：轴距
- 三条及以上：总跨度、平均轴距、各跨轴距、轴线角度
- 3D 场景会显示相邻轴距辅助线，以及首末轴线之间的总跨度辅助线
- 支持记录当前轴网结果，并随场景持久化、导出、截图和历史回看

## 近似值规则

当结果带有 `近似值` 标签时，通常表示命中了以下降级路径之一：

- 使用对象包围盒而不是真实轮廓
- 场地或对象 polygon 无效、自交或缺失
- 通过 footprint envelope 推断占地范围
- 通过楼层/区域高度推断净高或体积
- 通过屋顶/楼层边界组合推断建筑包络
- 路径或角度比较中混入曲墙、多段组合或非稳定几何

导出、复制文本、历史记录和场景固定标签都会保留 `近似值` 语义。

## 持久化与导出

- 距离记录和固定测量标注会持久化到当前场景 metadata
- 支持导出 `CSV`、`JSON`、`截图`
- 截图会叠加当前视角下的测量标签
- 最近测量会在面板中保留，方便快速回看

## 快捷键

- `M`：开关测量模式
- `Esc`：退出测量模式
- `1-7`：切换 距离 / 面积 / 体积 / 净空 / 角度 / 周长 / 轴网
- `F / H / V / P`：切换 自由 / 水平 / 垂直 / 路径测距

## 性能策略

当前测量模式已做这些优化：

- 距离模式 pointer move 走 `requestAnimationFrame` 节流
- 射线拾取只针对已注册节点 root，而不是整棵 scene children
- 场景对象与 nodeId 的映射做了缓存
- 大部分统计结果通过 memo 化按模式和选择集计算

如果后面继续优化，优先级建议是：

- 周长辅助线与标签的视锥裁剪
- 大体量场景下的 label 分层渲染
- 大量 pinned 标注时的批量合并与分页显示

## 当前边界

以下能力仍未完成或只完成了一部分：

- 更细的结构级性能 profiling
- 真正的柱网节点语义与结构约束

扩展新测量能力时，优先保持两层边界：

- `measurement.ts` 只负责几何与结果口径
- `measurement-mode.tsx` 只负责交互、可视化和导出联动
